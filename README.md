# oslo-hack

A one-page website that helps people in Oslo find others to build small projects with.

Open `index.html` in a browser. No libraries, no build step.

- `index.html` – page structure
- `style.css` – styles (mobile-first)
- `script.js` – mobile menu, session plan toggle, and "Getting there" (Entur + Oslo Bysykkel APIs)
- `photo.jpg` – hero image (illustration; replace with a real photo using the same name)

## Idea submissions

The "Suggest an idea" form emails submissions through [Web3Forms](https://web3forms.com).
Create a free access key there with the email address that should receive ideas,
then replace `YOUR_WEB3FORMS_ACCESS_KEY` in `script.js`.
